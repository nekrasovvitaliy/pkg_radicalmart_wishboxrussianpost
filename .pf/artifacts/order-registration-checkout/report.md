# Поля регистрации Почты России в checkout

## Результат

В существующую группу `shipping` формы checkout добавлены обязательные данные,
которые вводит пользователь для регистрации внутреннего отправления через API
Почты России:

- `recipient_name` — получатель;
- `index_to` — почтовый индекс (существующее поле);
- `region_to` — регион;
- `place_to` — населённый пункт;
- `street_to` — улица;
- `house_to` — дом.

Новые поля обязательны и используют локализованные подписи на русском и
английском языках. Текущая архитектура Joomla-формы сохранена: поля находятся
в `fields name="shipping"`, системные параметры API не вынесены пользователю.

В русских подписях регистрации и синхронизации устранены остаточные упоминания
СДЭК; теперь они последовательно называют Почту России.

## Основание

Контракт `PUT /1.0/user/backlog` из официальной спецификации API Почты России.

## Проверки

- XML формы корректен;
- все новые языковые ключи определены в `en-GB` и `ru-RU`;
- все пользовательские поля имеют `required="true"`.
- в изменённом контуре регистрации нет подписей СДЭК.
