# Одношаговая регистрация заказа в Почте России

## Результат

Плагин RadicalMart актуализирован под одношаговую регистрацию через
`RadicalMartOrderRegistrationService::register()` из библиотеки интеграции с
Почтой России.

Из обработчика удалён унаследованный от СДЭК двухшаговый контур:

- события создания, обновления и последующей синхронизации регистрации;
- UUID запроса и сущности;
- сохранение промежуточного ответа, ошибок и предупреждений DTO;
- перевод заказа в промежуточное состояние `PENDING`;
- неработающие подписки на отсутствующие методы и кнопка синхронизации.

Плагин теперь обрабатывает только `onRadicalMartAfterOrderSave`, передаёт заказ
в сервис регистрации и сохраняет текст исключения в
`russianpost_registration_error_message`, если сервис завершился с ошибкой.

## Проверки

- `php -l` для изменённого PHP-файла — успешно;
- в плагине отсутствуют CDEK-специфичные DTO и события двухшаговой регистрации;
- подписка события указывает на существующий публичный метод;
- регистрация вызывается через сервисы `OrderRegistration`, указанные оператором.
