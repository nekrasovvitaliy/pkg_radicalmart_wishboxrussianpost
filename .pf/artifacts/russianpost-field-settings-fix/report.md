# Исправление настроек полей checkout Почты России

## Причина

В `method.xml` одновременно находились два набора параметров:

- старые адресные `field_country`, `field_city`, `field_zip` и другие с вариантами `Hide/Show`;
- актуальные поля API Почты России с вариантами `required/not_required/hidden`.

Актуальный набор был вынесен в fieldset без привязки к вкладке `settings`, поэтому административная форма продолжала показывать старые бинарные параметры.

## Изменения

- удалены десять устаревших адресных параметров `Hide/Show` из формы метода доставки;
- fieldset полей Почты России переименован в `settings_fields` и привязан к `tab="settings"` по образцу standard shipping;
- сохранены семь актуальных параметров: получатель, индекс, регион, населённый пункт, улица, дом и квартира;
- для каждого параметра сохранены три состояния: обязательное, необязательное и скрытое;
- существующая обработка в preparer traits и checkout layout оставлена без изменения.

## Проверка

- оба XML-файла успешно прошли `xmllint --noout`;
- в `settings_fields` найдено 7 параметров;
- для каждого параметра присутствуют `required`, `not_required` и `hidden`;
- бинарных пар `0/1` с `JHIDE/JSHOW` в `method.xml` больше нет;
- имена семи параметров совпадают с preparer traits и проверками checkout layout.
