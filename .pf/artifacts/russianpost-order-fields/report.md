# Актуализация полей формы заказа

В `forms/radicalmart/order.xml` старые универсальные поля адреса заменены на актуальные поля доставки Почты России:

- `recipient_name`;
- `index_to`;
- `region_to`;
- `place_to`;
- `street_to`;
- `house_to`;
- `room_to`;
- `mail_type`.

Поле `room_to` оставлено необязательным. Служебные поля регистрации заказа, трек-номер, поля стоимости и административные поля сохранены.
